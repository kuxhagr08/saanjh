# APNA — Server Database Data Allowlist (`DATA_ALLOWLIST.md`)

> **Enforcement Notice:**  
> This file is the single source of truth for all database tables and columns permitted in the APNA backend database (PostgreSQL / SQLite).  
> The automated test `test_data_allowlist_ci_drift` inspects all application models and migrations. **If any table or column exists that is not on this allowlist, CI FAILS immediately.**

---

## Allowed Application Tables & Columns

### 1. `core_user` (Account & Auth Verifier)
- `id` (Primary Key, integer)
- `password` (Argon2id password hash / OPAQUE verifier record, NEVER plaintext)
- `last_login` (Timestamp)
- `is_superuser` (Boolean)
- `username` (Handle/username, string)
- `first_name` (String, default blank)
- `last_name` (String, default blank)
- `email` (Account email, unique string)
- `is_staff` (Boolean)
- `is_active` (Boolean)
- `date_joined` (Timestamp)
- `phone_number` (Optional contact discovery, string)
- `display_name` (Display nickname, string)
- `avatar_color` (Theme color, string)
- `avatar_url` (Public profile DP URL, string)
- `about` (Public bio/status, string)
- `status_visibility` (Privacy setting, string)
- `profile_photo_visibility` (Privacy setting, string)
- `read_receipts_enabled` (Boolean)
- `allow_phone_discovery` (Boolean)
- `allow_email_discovery` (Boolean)
- `allow_username_discovery` (Boolean)
- `messaging_permission` (Privacy setting, string)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

### 2. `core_device` (Registered User Devices)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `device_id` (Unique client device identifier, string)
- `device_name` (Client label e.g. "Pixel 7 Chrome", string)
- `user_agent` (Client user agent string)
- `last_active` (Timestamp)
- `created_at` (Timestamp)

### 3. `core_encryptionidentity` (Public Identity Keys)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `public_identity_key` (Base64 X25519 public key, string)
- `public_signing_key` (Base64 Ed25519 public key, string)
- `key_fingerprint` (Deterministic safety fingerprint string)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

### 4. `core_prekeybundle` (Asynchronous X3DH Public Prekeys)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `signed_prekey` (Base64 signed X25519 prekey, string)
- `signed_prekey_signature` (Base64 Ed25519 signature, string)
- `one_time_prekeys` (List of Base64 one-time public keys, JSON)
- `updated_at` (Timestamp)

### 5. `core_pushtoken` (Content-Free Wake-Up Tokens)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `device_id` (Device identifier, string)
- `token` (FCM / APNS push token, string)
- `platform` (Platform name e.g. "android", "ios", "web", string)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

### 6. `core_billingrecord` (Pro Subscription & Plan)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `razorpay_customer_id` (Payment gateway customer ID, string)
- `razorpay_subscription_id` (Payment gateway subscription ID, string)
- `plan` (Plan identifier e.g. "free", "pro", string)
- `status` (Subscription status, string)
- `current_period_end` (Timestamp)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

### 7. `core_samajprofile` (Public Social Profile)
- `id` (Primary Key, integer)
- `user_id` (Foreign Key to `core_user`)
- `bio` (Public bio text, string)
- `handle` (Social handle, string)
- `followers_count` (Integer)
- `following_count` (Integer)
- `is_verified` (Boolean)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

### 8. `core_samajfollow` (Social Follow Graph)
- `id` (Primary Key, integer)
- `follower_id` (Foreign Key to `core_user`)
- `following_id` (Foreign Key to `core_user`)
- `created_at` (Timestamp)

### 9. `core_samajpost` (Public / Follower Feed Posts)
- `id` (Primary Key, integer)
- `author_id` (Foreign Key to `core_user`)
- `post_type` (Enum: "post", "reel", string)
- `caption` (Public caption text, string)
- `media_blob_url` (Object storage CDN URL, string)
- `thumbnail_url` (Video thumbnail URL, string)
- `visibility` (Enum: "public", "followers", string)
- `view_count` (Integer)
- `likes_count` (Integer)
- `is_archived` (Boolean)
- `created_at` (Timestamp)
- `expires_at` (Optional expiration timestamp)

### 10. `core_samajcomment` (Public Post Comments)
- `id` (Primary Key, integer)
- `post_id` (Foreign Key to `core_samajpost`)
- `author_id` (Foreign Key to `core_user`)
- `text` (Comment text, string)
- `created_at` (Timestamp)

### 11. `core_samajstory` (24-Hour Ephemeral Social Stories)
- `id` (Primary Key, integer)
- `author_id` (Foreign Key to `core_user`)
- `media_blob_url` (Object storage URL, string)
- `caption` (Short caption, string)
- `created_at` (Timestamp)
- `expires_at` (Strict 24-hour expiration timestamp)

### 12. `core_safesharelink` (Safe Share Ephemeral Links)
- `id` (Primary Key, integer)
- `owner_id` (Foreign Key to `core_user`)
- `token_id` (Random opaque URL identifier, string)
- `blob_ref` (Object storage ciphertext reference, string)
- `expires_at` (Expiration timestamp, max 7 days)
- `is_revoked` (Boolean)
- `max_downloads` (Integer)
- `download_count` (Integer)
- `created_at` (Timestamp)
*(Note: Decryption key, original filename, and plaintext are strictly prohibited from this table and live in the URL `#fragment`)*

### 13. `core_userreport` (Abuse / Safety Reports)
- `id` (Primary Key, integer)
- `reporter_id` (Foreign Key to `core_user`)
- `reported_user_id` (Foreign Key to `core_user`)
- `reason` (Report category, string)
- `details` (Report explanation, string)
- `created_at` (Timestamp)

### 14. `core_moderationaction` (Administrative Moderation Records)
- `id` (Primary Key, integer)
- `target_user_id` (Foreign Key to `core_user`)
- `action` (Action type e.g. "warning", "temp_ban", string)
- `reason` (Moderation reason, string)
- `created_at` (Timestamp)
- `expires_at` (Action expiration timestamp)

### 15. `core_featureflag` (Dynamic Feature Toggles)
- `id` (Primary Key, integer)
- `key` (Feature flag name, string)
- `is_enabled` (Boolean)
- `description` (Description, string)
- `created_at` (Timestamp)

## Strictly Blocked Tables (MUST NEVER EXIST)

The following tables are **explicitly forbidden** and will fail CI if defined:
- `core_encryptedmessage` / `core_message` (Messages belong in Redis Ephemeral Mailbox or P2P WebRTC)
- `core_conversation` / `core_conversationmember` (Conversations and contacts belong on client devices)
- `core_encryptedbackupblob` / `core_backup` (Backups belong in `.apnabackup` user exports or user BYO-storage)
- `core_vaultitem` / `core_vaultfile` (Files belong strictly in client-side IndexedDB)
- `core_contact` / `core_addressbook` (Address books belong strictly on device)
- `core_aiconversation` / `core_prompt` (AI data belongs strictly on device)
- `core_task` / `core_habit` / `core_note` (Planner data belongs strictly on device)
